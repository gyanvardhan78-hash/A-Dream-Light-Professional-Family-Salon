# A Dream Light Professional Family Salon

Website for A Dream Light Professional Family Salon — luxury hair, skin, bridal and spa services in Dhirajganj, Jamshedpur.

## Development

You need Node.js (or Bun) installed.

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
